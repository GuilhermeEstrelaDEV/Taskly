# Taskly

Taskly é uma aplicação web de gerenciamento de tarefas desenvolvida com foco em simplicidade, organização e produtividade. A plataforma permite aos usuários criarem, visualizarem, editarem e excluírem tarefas com uma interface intuitiva e responsiva.

## Visão Geral

Este projeto foi criado com o objetivo de aplicar conhecimentos em desenvolvimento web utilizando tecnologias fundamentais como HTML, CSS e JavaScript. O Taskly simula um ambiente de lista de tarefas local e pode ser usado como base para aplicações mais robustas com backend.

## Funcionalidades

- Adição de tarefas com título e descrição
- Marcação de tarefas como concluídas
- Edição de tarefas existentes
- Exclusão de tarefas
- Interface limpa, responsiva e de fácil usabilidade

## 🛠 Tecnologias Utilizadas

- **HTML5**
- **CSS3**
- **JavaScript (ES6+)**
